Before installation

  • Confirm the exact platform and version.
  • Confirm admin access and whether managed installation is required.
  • Confirm that a current backup exists.
  • Confirm whether the store already uses custom import or export modules.

Recommended first test

  1. Export products.
  2. Make one small reversible change.
  3. Import the edited file.
  4. Re-export and confirm the change landed.

Large-file guidance

  • Test large imports on a copy or staging store first.
  • Use background worker or cron processing where available.
  • Keep the original export file for rollback and comparison.
  • Review the generated error report before retrying an import.
